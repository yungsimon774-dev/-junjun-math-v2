# Build015 · 竖式测试

首页新增“竖式测试”，每组5题，可选加法、减法、乘法、除法或四则混合，两位数或三位数。乘法为多位数乘一位数；除法为一位数除数，包含整除、余数及商中间的0。竖式按数位对齐。

加法、乘法填写进位（无进位填0）及结果各位；减法填写退位调整后的各位被减数及结果；除法填写商、每步乘积及余数。每一格都要正确才算本题竖式全对，空格及非法数字先提示补齐，不作为一次提交。第一次完整提交后锁定本题，完成本组可逐题查看参考过程和需复习的位置。

可选择解题提示，报告区分“竖式全对”和“未用提示全对”。每组记录、当前输入及已提交但尚未点下一题的状态保存在同一浏览器，关闭重开可继续。竖式测试独立记分，不修改已有课程掌握率、星星或课程答题统计。完成记录最近保存30组，随原有记录导出/导入。

验证包括：4,544组加减乘除参数及过程字段检查，额外连续进位、连续退位、商中间0和余数边界；每格漏填与错误值、全角数字、异常导入及待推进提交状态；手机尺寸Chromium五题测试、过程错误标红、提示分数区分、断网重开恢复、家长报告和原统计不变；原有题库、列式作答、实验台、存储和整包离线测试继续通过。不是物理手机/Safari验收。

新增应用文件 v12-vertical.js、v12-vertical-view.js，均包含在30文件离线摘要中。部署需整套更新，包括release-manifest.json。开发命令沿用 npm test、npm run test:browser；修改应用后 npm run release 更新摘要。
