# 峻峻数学大冒险 V12 Build010

基于当前线上 Build009 的代码升级，保留原有 26 门课程、21,509 道有效题和学习记录标识。新增探索题单独生成，不计入原题库数量，也不计入考试正确率。

## 本次改进

- 首页增加数学探索工坊和等量代换完整课程的直接入口。
- 探索分为一层代换、连续代换、先反推再代换三级；提供第一步检查、两种解法、改数字出题及文字想法记录。可由家长代记口述，不提供语音录音或语音识别。
- 最近14天内，同一题型最近5～6次全部无提示首次答对、至少5道不同题，且含迁移题，才作为减少重复练习的依据。全部题型满足、且无到期复习时，四阶段学习改为4道迁移挑战；部分满足时，基础阶段优先留给其他题型。随机练习保持自由抽题。
- 到期复习不因“已掌握”而省略。变式复习保留原题编号，更新原题的复习日期；有提示或纠正后答对时继续保留错题。
- 错因系统推测与孩子自述分开。孩子可选择看漏条件、计算错误、未理解关系或暂时说不清，家长报告据此提供陪学建议。
- 独立指标从本版开始按实际答题记录：独立、迁移、诊断、复习题中，无提示首次答对的比例；讲解和引导题不计入。旧记录不反推、不补造数据。
- 记录最初错误答案，修复纠错后可能用正确答案判断错因的问题；修复空白第一步被当作0、游戏快捷键干扰输入框的问题。
- 继续使用当前普通话语音策略，未更改语音语言设置。

## 使用与更新

这是静态网站，请用 HTTP 服务或 GitHub Pages 打开；不要直接双击 index.html 使用 file://。

升级包中的 index.html、v12-*.js、v12-style.css、courses.js、sw.js、manifest.json、icon.svg 和四个 wav 文件应保持在同一目录。无需上传 tests、package.json 或安装依赖来使用网站。

覆盖网站前，可在家长报告中导出学习记录作为备份。继续使用同一网址、同一浏览器时，已有本地记录沿用；换设备需要自行导出、导入，尚未增加云同步。

首次联网打开后确认顶部显示“V12长期版 · Build010 · 探索与精准教学版”。本版已更新资源版本和离线缓存名称。

- 核心逻辑测试通过：原题库质量审计、等量代换首题、乘法交换律、掌握证据门槛、减少重复练习、到期复习保护、独立统计、原始错答、复习日期推进、记录导入导出和 Build009 兼容。
