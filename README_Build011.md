# 峻峻数学大冒险 V12 Build011

基于 Build010 的真实代码升级，包含 Build010 的全部功能。原有26门课程、21,509道有效题与本地记录标识继续保留。

## 纠错之后换题独立验证

普通练习答错后（包括提示后改对），本轮会尽量隔一道题安排同题型、同结构、数字及答案不同的变式。每轮最多额外增加两道，避免无限加练；其他待验证内容保存在家长报告中。

验证使用填空，不受普通练习“只做选择”设置影响。只有首次无提示答对，才记录“本次变式独立通过”。使用提示、纠正后答对和再次答错分别保留不同状态，不把提示后完成当作独立通过。一次验证通过不等于整体掌握，原有多道题及迁移题的掌握证据要求仍然生效。

没有合适的同结构变式时保留待验证状态，不拿无关题替代、不自动判通过。能力诊断不插入额外题；验证失败也不无限追加验证题。家长报告可继续发起最多四道验证题。

## 不同卡点，使用不同引导

- 看漏条件：分别记录已知什么、题目问什么。
- 计算错误：展示该题已有的拆解和检查方法，记录计算与验算想法。
- 关系不懂：显示该题已有的关系图示，记录如何表示已知量及数量关系。
- 暂时说不清：记录先想到什么、卡在什么地方。

这些思路可由孩子填写或家长代记，系统只保存，不自动判断文字推理是否正确。系统推测错因仍与孩子自述分开。

## 开放思维挑战

首页增加“开放思维挑战”：

- 找多个答案：正整数分拆，同一总和接受不同合法组合，交换位置不算新答案。
- 补一个条件：先识别条件不足，再补一个数量条件，给出满足条件的数值。

允许表达发现、解释理由或提出新问题。只检查数值约束，不自动评价自由文字；不计入普通练习正确率。记录可在家长报告查看。
