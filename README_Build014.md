# 峻峻数学大冒险 Build014 · 完整列式作答

适合列式的题默认改成四格填写：`[6] [×] [5] = [30]`。两个数、运算符和结果均不预填。等号固定显示。运算符从加、减、乘、除中选择；数字使用系统键盘输入。原有用户升级后自动启用，可在学习设置关闭“列式并计算”。该设置优先于其他题的选择/填空设置。

当前21,509道有效题中，11,048道可以可靠提取列式路径，其中907道需要分步填写。加、乘允许交换操作数；减、除保留顺序。输入必须同时符合本题的数量关系和结果，不能只凑出一个相同得数。多步题按当前讲解的分步路径填写。比较、单位、余数以及不能可靠提取列式路径的题继续使用原有答题界面，不生成未经校验的算式。讲解例题仍然先展示方法，不计分。

空格或未选择运算符时只提示补全，不记错。错误的完整列式按原有“先自己改一次”规则处理，第一份错式和改正后的完整算式随答题记录保留。题号和记录存储键保持不变，旧成绩继续保留。

验证：全库可列式题正确路径、结果错误、操作数错误、加乘交换/减除顺序、空白和非法输入检查；页面补全和提交、旧记录兼容；Chromium手机尺寸及桌面回归、离线整包校验与断网重开。手机物理设备与Safari尚未实测。

开发：Node.js 24+，`npm ci`、`npm test`。安装Playwright Chromium后执行`npm run test:browser`。修改应用文件后执行`npm run release`更新28个资源摘要。静态部署需同时包含新文件`v12-equation.js`和`release-manifest.json`。
