V12长期版 · Build007 · 终极学习系统版 · 最高能力教学版

这是V12系列当前唯一主版本。Build007直接由已实测的Build006升级而来，不删课程、题库、学习记录或原有功能，不以并行版本冒充完成。

一、Build001：长期架构与旧版迁移
1. 课程、五组外接题库、知识图谱、学习引擎、教学引擎和数据层分开。
2. 题库仍在本机运行，不依赖在线大模型。
3. 首次启动自动读取V11记录，迁移星星、成绩、错题、课程进度和设置。
4. V11原记录不会被删除。

二、Build002：真正的知识模型
1. 26门课程全部接入知识图谱，包含领域、顺序、目标和前置课程。
2. 用首次正确、自主纠错、提示次数、练习次数、迁移表现和近期练习计算掌握度。
3. 15题能力诊断覆盖不同知识领域。
4. 自适应选题优先薄弱点、错题同类变式、到期复习和未见新题。
5. 自动避免同题和相同模板在一组中反复出现。

三、Build003：四阶段学习闭环
1. 讲解：先看完整例题和思路，不计分。
2. 引导：给方法和分步检查，但不直接公布最终答案。
3. 独立：尽量使用填空或数学符号输入，减少猜选项。
4. 迁移：用综合题、生活题或高阶题检查是否真正会用。
5. 设定的每组题量只计算需要孩子作答的题，讲解例题另加1题。

四、Build004：长期记忆与家长诊断
1. 每道练习按0、1、3、7、14、30天安排间隔复习。
2. 第一次答错可先看提示并自主修改。
3. 首次正确与自主纠错分开统计，不用第二次答对虚增正确率。
4. 自动分析单位换算、进位、退位、等量关系、规律、图形、数量关系和计算细节等错因。
5. 家长报告包含7天趋势、薄弱知识点、主要错因、错题和复习日期。

五、Build005：终极整合
1. 四阶段、智能强化、间隔复习和随机练习四种模式。
2. 每组可选8、12、16或20道作答题。
3. 支持智能防猜、尽量填空和只做选择。
4. 支持纯数字、带单位数字、双空、比较符号和算式输入。
5. 分类型教学覆盖加减乘除、应用题、等量代换、单位、图形、规律和搭配。
6. 数学工具箱包含数位、厘米、人民币和分钟换算。
7. 每日计划、连续奖励、8项成就和专注模式。
8. 学习记录可导出、导入；清除记录需家长密码2026。
9. 严格只使用普通话系统语音；没有普通话语音时停止朗读，不改用广东话。
10. 首次联网加载成功后，支持离线继续使用。

六、Build006：教学逻辑增强
1. 教学器改为“识别题型→选择孩子当前阶段适用的方法→校验算式→分步展示”的统一流程。
2. 讲解覆盖24类教学方法，包括四则运算、两步应用、逆推、和差、鸡兔同笼、周期、余数处理、组合、方向、单位、图形与统计。
3. 逆推题不再误认成普通混合运算；文字题只有在本身是纯算式时才使用混合运算规则。
4. 引导阶段只给方法和分步检查，不显示完整解答；讲解例题和作答结束后才显示结果。
5. 首次答对、自主纠错和答错后的反馈全部改用同一套已校验讲解，不再绕过教学器显示旧题库短句。
6. 加法补全最高位进位；减法讲清连续0的逐位退位；有余数除法分别按商和余数校验；负数逆推正确保留负号。
7. 和差问题使用“先拿走多出的部分，再平均分”的纸条思路；鸡兔同笼使用二年级可理解的假设法并逐步验算。
8. 保持schemaVersion 12和原本机存储键不变，可直接覆盖安装并继续原学习进度。

七、Build007：最高能力教学版
1. 557种原始题型标签全部进入43类专属教学流程，通用“先理解题意”兜底路由降为0。
2. 新增取整、数位、往后数、凑整、数位交换、估算、余数、连续数配对、算式选择等题目专属讲法。
3. 每道能提取算式的题都会生成“算式＝？”的题目专属提示，引导阶段只给关系，不提前给结果。
4. 答错后根据峻峻刚才填写的答案区分“停在中间步骤、商余数混淆、加减关系看反、乘法只算一次加法”等错因，再给针对性纠正。
5. 新增纸条图、取整位置图、分组图，并对引导阶段图示做答案遮蔽。
6. 自动修复旧题库55处语义缺陷：30道和差关系、7道负数库存、2道付款不足找零、16道人物指代。
7. 修题时保留原题qid，不会因为题面修正而丢失已有练习、错题和复习记录。
8. 保持schemaVersion 12、本机存储键、26门课程、22,456题及全部原功能不变，可直接覆盖安装。
