峻峻数学大冒险
V12长期版 · Build005 · 终极学习系统版

这是V12系列的最终整合版。V12内部共完成5个开发阶段，最终只交付Build005。

一、Build001：长期架构与旧版迁移
1. 课程、五组外接题库、知识图谱、学习引擎、教学引擎和数据层分开。
2. 题库仍在本机运行，不依赖在线大模型。
3. 首次启动自动读取V11记录，迁移星星、成绩、错题、课程进度和设置。
4. V11原记录不会被删除。

二、Build002：真正的知识模型
1. 26门课程全部接入知识图谱，包含领域、顺序、目标和前置课程。
2. 用首次正确、自主纠错、提示次数、练习次数、迁移表现和近期练习计算掌握度。
3. 15题能力诊断覆盖不同知识领域。
4. 自适应选题优先薄弱点、错题同类变式、到期复习和未见新题。
5. 自动避免同题和相同模板在一组中反复出现。

三、Build003：四阶段学习闭环
1. 讲解：先看完整例题和思路，不计分。
2. 引导：给方法和分步检查，但不直接公布最终答案。
3. 独立：尽量使用填空或数学符号输入，减少猜选项。
4. 迁移：用综合题、生活题或高阶题检查是否真正会用。
5. 设定的每组题量只计算需要孩子作答的题，讲解例题另加1题。

四、Build004：长期记忆与家长诊断
1. 每道练习按0、1、3、7、14、30天安排间隔复习。
2. 第一次答错可先看提示并自主修改。
3. 首次正确与自主纠错分开统计，不用第二次答对虚增正确率。
4. 自动分析单位换算、进位、退位、等量关系、规律、图形、数量关系和计算细节等错因。
5. 家长报告包含7天趋势、薄弱知识点、主要错因、错题和复习日期。

五、Build005：终极整合
1. 四阶段、智能强化、间隔复习和随机练习四种模式。
2. 每组可选8、12、16或20道作答题。
3. 支持智能防猜、尽量填空和只做选择。
4. 支持纯数字、带单位数字、双空、比较符号和算式输入。
5. 分类型教学覆盖加减乘除、应用题、等量代换、单位、图形、规律和搭配。
6. 数学工具箱包含数位、厘米、人民币和分钟换算。
7. 每日计划、连续奖励、8项成就和专注模式。
8. 学习记录可导出、导入；清除记录需家长密码2026。
9. 严格只使用普通话系统语音；没有普通话语音时停止朗读，不改用广东话。
10. 首次联网加载成功后，支持离线继续使用。
