# 峻峻数学大冒险 V12 Build012

基于 Build011 的实际代码升级，包含 Build010、Build011 全部功能。原有26门课程、21,509道有效题与本地记录标识继续保留。

## 新增：首页数学实验台

### 逐层代换

根据“一个苹果等于几个单位块、一个梨等于几个苹果”，把梨换成苹果，再把每个苹果换成单位块。每一步转换保持总量不变。水果可以直接点按，也可以拖到代换区；全部换成单位块后，再填写并检查总量。尚未完成代换时，不能仅凭输入最终数字标为完成。

### 等式天平

左盘放一个待求值的苹果及若干单位块，右盘放等量的单位块。可以单边加减、两边同时加减，也可以把单位块拖到另一盘，观察天平变平或向较重一侧下沉。

目标是让左盘只剩一个苹果、右盘留下等量单位块，再填写苹果的值。单纯恢复初始平衡不算完成。单边操作是观察实验，允许暂时失衡；单位块数量不会变成负数。

### 操作、记录与继续

- 不依赖拖动：全部数学目标也能通过点按按钮完成；按钮可以用键盘操作。
- 支持撤回，上限保留40步；支持换题、切换实验模式及提示。
- 当前草稿自动保留，关闭后重新打开继续；每种模式最近的操作和文字想法进入家长报告。切换模式后，当前草稿转为新模式，旧模式记录仍保留。
- 最多保留40条图示学习记录；每条保留最近40次操作。
- 图示练习属于有支架的观察与操作学习，独立记录，不增加普通答题次数、正确率、星星或掌握证据。未点提示也不自动认定为独立掌握。
- 文字可由孩子或家长记录，不自动评价解释是否正确。

## 使用

完整升级包为静态网站，通过 HTTP 服务或 GitHub Pages 访问；不要双击 index.html 使用 file://。日常使用无需安装 Node.js。部署时完整保留压缩包内文件结构。

页面顶部应显示“V12长期版 · Build012 · 动手图示与等量实验版”。资源参数和离线缓存名称已更新。代码包不代表原网址已上线；线上版本以实际网页顶部为准。

开发环境安装 Node.js 24+ 和 npm依赖后运行 npm test。npm run test:browser 为浏览器回归入口，需要可运行的Playwright Chromium和本地HTTP服务。
