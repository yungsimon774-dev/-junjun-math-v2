# Build016 · 直接显示的屏幕键盘

完整列式作答现在直接显示一排1–9、0数字键；下一排为加、减、乘、除、等号。另有小数点、正负切换、删除、清空本格和下一格。数字格和符号格改为只读屏幕输入，不调用手机系统键盘或运算符下拉菜单。点选任意格即可修改，当前格高亮，键盘标明正在填写的位置。

例：依次点6、×、5、=、3、0，可填入6×5=30。运算符键设置当前行的运算符并切到第二个数，等号键切到该行结果；等号仍是固定的算式结构，不需重复填。多行题逐行使用同一键盘，两个操作数、符号和结果依然全部判题。键盘也支持电脑数字键、x/*、/、退格及Tab切换。

竖式同步改用屏幕数字键盘。普通数位填一位后自动移到下一格；退位调整格可填两位，单数字可点下一格。输入时立即保存到原有测试进度。提交后锁定，不改变原有测试评分、提示区分和课程成绩。

验证：屏幕按键连续填写6×5=30、删除/清空、符号和结果切换、小数与正负、物理键盘映射；算式没有下拉选择且所有计算输入为readonly/inputmode=none；真实Chromium手机尺寸通过屏幕点击完成算式纠错和五题竖式测试，断网重开恢复和家长报告继续通过。原有题库、判题、竖式计算、导入和资源摘要检查通过。iOS/Safari物理设备尚未实测。
