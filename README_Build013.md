# 峻峻数学大冒险 V12 Build013 综合质量验证版

本版是在 Build012 上进行的一次完整整合，包含此前 Build010～012 的教学、纠错验证、开放题和图示实验台。没有把版本号称为能力上限；交付目标是修复本轮发现的问题，并给出实际完成的验证。

## 本次实质改进

### 更诚实的课程进展

原先按少量已练题型估计进展，可能出现反复练一个结构，就把整门课的表现估得过高。本版按“课程、题型和题目结构”区分1,004个学习单元，未练结构计0，各结构等权平均；年级进展按当前年级的课程计算。

旧的原始答题、成绩和星星继续保留。新口径的进展可能下降，这不代表删除成绩或孩子退步。进展只是练习估计，不是能力测量或教学效果证明。

减少重复练习也使用结构级的近期独立答题证据，防止一个结构的表现被用于跳过别的结构；到期复习继续保留。纠错验证优先选择未练过的合适变式，后续验证避开此前用过的变式。

### 判题和学习流程边界

- 空白、空数组、非数字对象、十六进制和科学计数法不再被当成普通数字答案；保留正常数字、前后空格和全角数字的识别。
- 两空题要求两个答案都有效，修复可能把空白当作0的边界。
- 修复两空题键盘退格，以及已答完后继续点提示的问题。
- 同一场学习完成奖励只记录一次，避免重复触发；学习分钟按答题用时累计，避免把长时间停留直接算作学习。

### 记录保护与可恢复导入

- 本地保存被浏览器限制或空间不足时，页面明确提示，不会只显示保存成功。
- 导入前自动保留一份当前记录，可从家长报告恢复；导入保存失败时，当前记录不替换。
- 异常的原始记录另存，家长报告提供原文导出；不能备份时，不覆盖原记录。
- 不支持的未来记录版本不覆盖。有效的旧版记录继续兼容；异常计数和结构做边界规范化。
- 这些备份仍在同一个浏览器内。清除浏览器数据仍可能同时清掉它们，请定期手动导出到文件。尚未添加云同步。

### 整套离线文件校验

新增 release-manifest.json，对27个应用文件逐一验证SHA-256。只有整套内容匹配，才保存为可用离线版本，避免部署过程中把新旧文件混合使用。

新版本等待用户选择更新并重新载入；现有打开页面继续使用自己的版本缓存。旧版本缓存不会在本次更新时强制清理，以保护仍打开的旧页面。离线文件缓存与学习记录不是同一种备份。

### 图示实验台触控修复

真实浏览器检查发现，原来的单位块位置可能在小屏滚动后与投放盘无法同时看到。本版将单位块移到天平上方，触控拖入已通过验证。逐层代换、点按替代、撤回和操作恢复继续保留。

## 使用与更新

这是完整静态网站包，包含此前功能。部署时保留包内文件结构，务必一起上传 release-manifest.json。通过 HTTP 服务或 GitHub Pages 访问，不要双击 index.html 使用 file://。

覆盖前先导出学习记录。继续使用同一网址、同一浏览器时沿用原记录；换设备需要导入。若旧页面仍显示旧版本，可在导出后关闭该网站的所有旧标签，再重新打开，或使用页面更新提示。

顶部应显示“V12长期版 · Build013 · 综合质量验证版”。代码包和草稿PR不代表原网址已经上线，线上版本仍以网页显示为准。

## 开发验证与后续改动

使用Node.js 24+，执行 npm ci 后运行 npm test；浏览器检查先安装Playwright Chromium，再运行 npm run test:browser。浏览器脚本自带本地测试服务，不必另开服务器。

修改应用源文件后执行 npm run release 更新资源摘要，再运行测试。发布时应使用新的资源版本号，避免原地修改同版本缓存。新增GitHub Actions工作流用于后续PR和主分支的回归检查；本次实际验证结果来自本地运行，不预先宣称远端CI已通过。
